# PotBot — content & brand voice

How PotBot talks. Goal: make people want to use it — like a sharp marketer/salesperson, but with
zero fluff ("без пыли в глаза"). Honest, concrete, human.

## Voice
- **Human, first-person, founder-led.** Real sentences, not bullet soup. A hook that pulls you in
  (a small story, a sharp question, a true pain).
- **Sell the outcome, not features.** Talk about the reader's situation and what changes for them.
- **Concrete and honest.** Real numbers, real status. Say "live on devnet, mainnet next" — don't
  overclaim. Honesty is the differentiator.
- **Confident, not hypey.** No "revolutionary", no empty superlatives, no emoji spam.

## Formatting rules
- No em-dashes (—). Use commas, periods, or parentheses.
- Don't mention Drift in DeFi integration lists (use Jupiter, Kamino).
- Emojis: sparingly. 🍯 is the brand mascot accent; fine to end a thread with one.
- X threads: tweet 1 is a hook (story/question/pain), each tweet earns the next, end with one clear
  low-friction CTA (follow @PotBot_sol / DM to start a POT).

## Core message (the cocktail)
Group capital, governed by the group. One non-custodial vault on Solana. Funds live in a program,
not with a person or a bot. AI proposes, humans vote (bounded autonomy, timely after 2026 hacks).
Composable NAV shares. A simple, gamified way for newcomers to join (email + card), and a way for
experts to create pots and monetize their edge.

## Proof points (use real ones)
Live open-source DApp on devnet · governance + AI agent + Jupiter swaps · MCP server on npm ·
100/100 VaultMind AI security · backed by Superteam NL · mainnet next.
Category validation when useful: Morpho ($10B+ curated vaults), Midas ($50M raised).

## Audiences
- Newcomers: "trade with your friends without "trust me, I've got the wallet"." Easy, safe, fun.
- Experienced/creators: spin up a Strategy Vault, bring your audience, earn entry/performance fees.
- Investors/accelerators: non-custody + group governance + bounded AI + onboarding moat; live, not a deck.

## Don't
- Don't fabricate metrics; if unsure, ask or use a range.
- Don't bury the lede in features; lead with the human problem.
- Don't write a press-release tone; write like a person who built it.

## Quick checklist before posting
Hook in line 1? Honest about stage? Outcome-focused? No em-dashes / no Drift? One clear CTA?
