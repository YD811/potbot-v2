# Feature Status Language

Use these labels consistently across the website, README, deck, grant applications, and demos.

- **Live**: deployed and usable through the public production interface.
- **Devnet live**: deployed on Solana devnet and exercised end to end.
- **Implemented, pending deployment**: code exists but the advertised deployment does not include it.
- **Prototype**: demonstrable but relies on mocks, stubs, manual execution, or non-production assumptions.
- **Planned**: specification or roadmap only.

## Current positioning rule

The mainnet MVP is a single-asset yield POT with liquid, redeemable shares. Multi-asset baskets, tokenized equities/RWAs, Apple Pay funding, and using POT shares as third-party lending collateral must remain **Planned** until the corresponding providers, programs, and production flows are integrated and verified.

Governance, MCP, Blinks, Money Tree, Duels, NFTs, and privacy features may remain in the repository, but they are supporting or experimental layers rather than the primary MVP promise.
