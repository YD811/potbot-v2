## Идея в одном абзаце

PotBot — это групповые торговые сейфы на Solana. Представь: ты с друзьями хочешь торговать вместе. Сейчас для этого нужен либо один человек с доступом ко всем деньгам (риск доверия), либо огромная юридическая конструкция (MultiSig + документы). PotBot решает это за 2 минуты: создаёшь POT, зовёшь участников, они заходят с SOL или USDC, все голосуют за трейды — и программа исполняет их атомарно. Никто не держит ключи. Контракт — это и есть кошелёк.

---

## Что такое POT

POT — это on-chain сущность, которая хранит:
- **Vault** — реальный кошелёк на блокчейне с деньгами группы
- **Shares** — пропорциональные доли каждого участника (не токены — просто записи в аккаунте)
- **Tamagotchi** — живое существо, которое эволюционирует вместе с активностью группы
- **Governance Level** — правило, сколько голосов нужно чтобы исполнить трейд

## Механика шейров (Shares) — как это работает

Это самая важная часть. Объясняю по-простому:

### Вход в POT

Когда участник делает депозит:
```
Ты кладёшь 1 SOL → получаешь шейры
Шейры = твой депозит / общий vault × total_shares
```

**Пример:**
- POT создан. В нём 0 SOL, 0 шейров
- Саша вносит 5 SOL → получает 5,000,000 шейров (базовая единица: 1 SOL = 1,000,000 шейров)
- Женя вносит 3 SOL → получает 3,000,000 шейров
- Итого в vault: 8 SOL, 8,000,000 шейров
- Саша владеет 62.5% POT, Женя — 37.5%

### Рост vault

Если POT совершает трейд и зарабатывает:
- В vault теперь 10 SOL (было 8)
- Шейры не меняются — их по-прежнему 8,000,000
- Но цена 1 шейра выросла: было 0.000001 SOL, стало 0.00000125 SOL
- Саша при выходе получает: 5,000,000 × 0.00000125 = **6.25 SOL** (зарабатывает вместе с POT)

### Выход

```
Получаешь = твои_шейры / total_shares × vault_balance
```

Это честная математика. Никакого доверия к людям — только к программе.

## Что можно вносить в POT

На данный момент:
- **SOL** — нативный токен Solana
- **USDC** — стейблкоин (USD Coin, 6 decimals)
- **USDT** — стейблкоин (Tether, 6 decimals)

Когда ты вносишь USDC, программа конвертирует в "условный SOL" по текущей цене Jupiter для расчёта шейров. Это называется **normalized accounting** — всё хранится в единой единице учёта (SOL), но физически vault держит разные токены.

## Governance — кто решает что торговать

У каждого POT есть уровень управления (L0–L4):

| Уровень | Название | Правило |
|---------|----------|----------|
| L0 | Autocracy | Создатель решает единолично |
| L1 | Majority | Простое большинство по шейрам |
| L2 | Supermajority | >66% шейров |
| L3 | Weighted | Взвешенное голосование с delay |
| L4 | Consensus | Все должны проголосовать |

Голоса считаются **по шейрам**, не по головам. Если у тебя 60% шейров, твой голос весит 60%.

## Proposal — жизненный цикл трейда

```
1. Участник создаёт Proposal
   → "Купить 2 SOL BONK через Jupiter"
   → Указывает: input_token, output_token, amount, slippage, min_out

2. Голосование открыто
   → Участники голосуют ДА/НЕТ своими шейрами
   → Дедлайн: например, 24 часа

3. Кворум достигнут
   → Программа автоматически исполняет трейд через CPI → Jupiter
   → Vault получает новые токены

4. Tradeblock закрыт
   → XP начислено Tamagotchi
   → История трейда записана on-chain
```

## PnL — как считаем прибыль/убыток

Для каждого трейда, совершённого через Proposal:
- Сохраняем **entry price** (цена в момент исполнения, из Jupiter)
- Регулярно обновляем **current price** (из Jupiter Price API)
- PnL = (current_price - entry_price) / entry_price × 100%

**Пример:**
- Купили BONK по $0.000012 за 100 SOL
- Сейчас BONK стоит $0.000015
- PnL = +25%
- В SOL: vault вырос на 25 SOL (25%)

## Strategy Settings — что делать с позицией

Когда трейд исполнен, участники могут настроить стратегию выхода:

- **Stop-Loss** — автоматически продать если цена падает на X%
- **Take-Profit** — автоматически продать если цена растёт на X%
- **Max Allocation** — не более Y% vault в одном токене
- **DeFi Routing** — если позиция пассивная, автоматически отправить в yield (Kamino, Drift, MarginFi)

Это голосуется отдельным Proposal типа `SET_STRATEGY`.

## Tamagotchi — зачем он нужен

Это геймификация, которая делает DeFi эмоциональным. Групповой торговый сейф — это скучно. Но групповой торговый сейф, у которого есть живое существо, которое умирает если группа не торгует, а процветает если POT растёт — это совсем другая история.

**XP система:**
- +1 XP за каждый доллар внесённого депозита (Volume XP)
- +50 XP за каждый исполненный трейд (Trade XP)
- +10 XP за каждый поданный голос (Governance XP)

**6 стадий:**

| Стадия | Эмодзи | Порог XP |
|--------|--------|----------|
| Egg | 🥚 | 0 |
| Seedling | 🌱 | 100 |
| Sprout | 🌿 | 500 |
| Plant | 🪴 | 2,000 |
| Bloom | 🌸 | 10,000 |
| Legend | 🌳 | 50,000 |

## Почему Solana

1. **Скорость** — 400ms блоки, трейды исполняются мгновенно
2. **Стоимость** — $0.00001 за транзакцию. При 100 трейдах в месяц — $0.001
3. **Anchor** — лучший фреймворк для умных контрактов. Rust = безопасность
4. **Экосистема** — Jupiter, Kamino, Drift, MarginFi — всё доступно через CPI
5. **Хакатон** — Solana Frontier 2026 = идеальное место для запуска
