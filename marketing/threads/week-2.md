### 2/ Jupiter v6 is live
Plugged the full Jupiter v6 swap stack into governance proposals:
• Token search w/ live quotes
• DEX route visualization
• % sliders + slippage
• Real wallet balance

Vote passes → swap executes → vault rebalances. No CEX. No middleman.

---

### 3/ Governance 2.0
Real on-chain guardrails shipped:
• Quorum % + approval % per pot
• Risk profiles (conservative / balanced / degen)
• Budget grants wizard (3-step)
• Trade size limits
• VoterRecord PDA → zero double-voting

No more "we trust Vitalik with the multisig." Code enforces it.

---

### 4/ AI Agent 🤖
Each pot gets a configurable rules engine:
• "Auto-propose buy if $X drops >10% in 24h"
• "Take-profit at +30%"
• Rate-limited so it can't spam
• Full log of agent actions in UI

Humans vote. Agent just raises its hand. 🙋

---

### 5/ ETF tokenization + yield
This is the fun one.
Every pot can tokenize its shares → tradable ERC-20-style token for the basket.
Plus yield panel: park idle SOL in Meteora / JLP (hJLP) while proposals cook.

Your group = a mini ETF.

• RugCheck integration
• Token metadata verification

Because nothing kills a DAO faster than one guy proposing "let's buy $PONZU."
